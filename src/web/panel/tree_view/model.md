# 命名空间树视图

`namespace_tree_view.tsx` 组织递归渲染与共享 Tooltip，`tree_props.ts` 定义树数据和草稿操作接口；视图仅调用上层操作，不保存 Profile 草稿。

树渲染体系保持独立，不为原树节点添加布局模式。组件直接放在本目录，不再为单个 TSX 文件创建目录。

`namespace_node.tsx` 渲染命名空间块，接收递归内容，名称编辑通过共用的 name_width.ts 回调取原始名称与 20 个字符宽度的较大值，描述编辑显式启用多行，宽度回调取文本起点到右侧按钮区域之前的可用宽度并保留行间距；`tree_children.tsx` 保持展开容器及收起过渡后的内容清理。`command_node.tsx` 渲染命令行，名称编辑复用 name_width.ts 的同一宽度回调，`namespace_placeholder.tsx` 提供新增命名空间、选择工具和空位拖放。`../../ui/controls/editable_text.tsx` 提供共享局部文本编辑，`tree_controls.tsx` 共享固定、禁用和删除按钮，`native_drag.ts` 处理原生拖动反馈。保留原有 DOM 层级、类名、权限和事件行为。


`tree_details.tsx` 提供命名空间与命令详情及共享锚点绑定。命令内的原始名称拥有独立 Provider，展示与工具卡片相同的 ToolDetails；命令统计复用 ToolStatistics。

命令简化注释优先使用当前挂载路径的映射注释，其次使用显式工具注释；未配置或内容为空白时显示“无”（英文为 None），不从完整文档提取。完整注释独立展示工具原始文档。

树锚点点击、双击和开始拖动时关闭浮层，避免展开命名空间后旧浮层遮挡下一行。

树锚点在指针按下时立即关闭浮层，并忽略该次指针交互引发的聚焦，避免浮层在点击完成前跳到行左下角；键盘聚焦仍使用锚点边界定位。

命令详情及原始命令的二层详情均展示全局总查询次数，按物理工具 ID 合并别名；命名空间详情展示该完整路径的全局查询次数，不累加子节点查询。


命名空间下拉按钮占满块高度，无独立圆角，由块外框裁剪；成员块左边缘与下拉按钮右侧对齐，共享按钮宽度与缩进变量。子列表使用虚线绘制父子树连接，末项处终止竖线，保留展开与收起动画。

子列表通过 flex gap 统一行间距，顶部间距由首项外边距提供，避免收起后列表内边距残留空白；命名空间条目使用两行 grid 分离节点行与展开子树；横向虚线及末项竖线终点按第一行实际高度居中，不使用固定像素高度。命令块与新增入口保留 flex 横向布局，连线坐标补偿命令块与新增入口的边框，竖线跨过行间距连续连接。
