# 悬浮提示

`tooltip.tsx` 提供 TooltipProvider、Tooltip 与 useTooltip。Provider 共享一个浮层，Tooltip 使用 popover 顶层以覆盖模态对话框并避免滚动区域裁切。鼠标移动直接更新浮层坐标，不触发工具卡片重渲染；在锚点静止悬停 500ms 后固定当前浮层位置，后续移动不再跟随，触发其它浮层时重新计时；浮层在视口边缘翻转、限位。锚点控制进入、离开和键盘聚焦。按住 Ctrl 固定当前浮层的位置与内容，释放后恢复跟随；离开锚点后取消未完成的静止计时，保留 200ms 供鼠标跨入浮层；只有已静止固定或按住 Ctrl 时，移入浮层才能持续显示，未静止时即使移入浮层仍会关闭。未固定浮层透传鼠标事件，避免快速移动时遮挡下方锚点、导致下一条提示无法触发；静止固定或按住 Ctrl 后才接收鼠标交互。内容超出视口高度时显示原生滚动条，鼠标不在浮层内时以 25px/s 自动往返滚动，初次显示及两端稍作停留；鼠标移入立即暂停自动滚动并允许手动滚动，移出后从当前位置恢复。页面隐藏时暂停，组件卸载时取消动画。浮层内滚动不关闭提示，锚点区域滚动及 Escape、选中工具或窗口失焦关闭提示。

浮层背景使用主题基础背景色，减少透明底色导致的下层内容透出，文字与代码高亮保持原始清晰度。

Ctrl 键盘状态在窗口捕获阶段同步，避免宿主快捷键截断冒泡事件；窗口捕获阶段的鼠标移动同时同步 ctrlKey，使按住 Ctrl 后才挂载的嵌套 Provider 以及漏收键盘事件的 Provider 能恢复状态，并取消待执行的关闭计时。

Provider 支持在浮层内容内嵌套使用；参数表拥有独立 Provider，第二层提示不会替换工具详情。二层 popover 保持在一层浮层的 DOM 子树内，悬停二层时父层保持打开并暂停自动滚动。

tree_details.tsx 提供命名空间与命令详情及共享锚点绑定。命令内的原始名称拥有独立 Provider，展示与工具卡片相同的 ToolDetails；命令统计复用 ToolStatistics。

命令简化注释优先使用当前挂载路径的映射注释，其次使用显式工具注释；未配置或内容为空白时显示“无”（英文为 None），不从完整文档提取。完整注释独立展示工具原始文档。

树锚点点击、双击和开始拖动时关闭浮层，避免展开命名空间后旧浮层遮挡下一行。

树锚点在指针按下时立即关闭浮层，并忽略该次指针交互引发的聚焦，避免浮层在点击完成前跳到行左下角；键盘聚焦仍使用锚点边界定位。

命令详情及原始命令的二层详情均展示全局总查询次数，按物理工具 ID 合并别名；命名空间详情展示该完整路径的全局查询次数，不累加子节点查询。
