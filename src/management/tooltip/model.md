# 悬浮提示

`tooltip.tsx` 提供 TooltipProvider、Tooltip 与 useTooltip。Provider 共享一个浮层，Tooltip 使用 popover 顶层以覆盖模态对话框并避免滚动区域裁切。鼠标移动直接更新浮层坐标，不触发工具卡片重渲染；浮层在视口边缘翻转、限位。锚点控制进入、离开和键盘聚焦。按住 Alt 固定当前浮层的位置与内容，释放后恢复跟随；离开锚点后保留 200ms 供鼠标跨入浮层，鼠标位于浮层内时持续显示。内容超出视口高度时显示原生滚动条，仅通过用户操作手动滚动，不自动滚动；浮层内滚动不关闭提示，锚点区域滚动及 Escape、选中工具或窗口失焦关闭提示。
