# 本地化与原生桥接

`zh.ts` 与 `en.ts` 定义同一套界面文案，`locale.tsx` 提供语言选择、插值及 React 上下文。`native_panel.tsx` 将宿主语言订阅桥接到管理面板。固定运行时命令的描述由 runtime/builtins.ts 提供英文原文；命名空间操作抛出翻译键，不再硬编码中文。整理草稿提示位于中英文界面翻译表。

整理草稿提示要求分别生成并保存 General（全部命令）、Base（仅 bash 与 edit 两个外部工具，完整固定）和按用途划分的 Profile；所有命令（包括固定等级 2）必须仅以一句简短英文描述表达核心功能，不得使用其他语言，不描述参数、选项、返回值或示例；根据 totalCalls、交互需求与用途分级固定，等级 2 固定完整定义、等级 1 仅固定名称和简短英文功能描述；逐 Profile 校验无重复挂载、包含根节点的 floor(N/3) 扇出限制，以及所有命令功能描述均为简短英文句子，最终汇报名称、用途与命令数量。

管理接口和会话 Profile 接口的固定校验错误返回共享翻译键，管理面板及会话 Toast 在呈现时翻译；外部错误文本保持原文。会话按钮无障碍名称、失败详情和工具来源的完整插值模板、下载文件名回退均由中英文词典定义。独立页面 HTML 的初始标题和加载文案复用英文词典，客户端启动后按浏览器语言呈现。

Profile 名称无效、重名、最后一个配置删除和 revision 冲突，以及命名空间路径与根保留字校验均抛出共享翻译键；界面取 Error.message 呈现，避免 Error: 前缀。固定会话配置错误 session_profile_locked 使用同一词典。会话 Profile 请求将 JSON 解析失败映射到 invalid_json_body，将结构校验失败映射到 invalid_session_profile_request，不直接显示解析器错误。
