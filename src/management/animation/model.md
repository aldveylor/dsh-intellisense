# 界面动画

`action_animation.ts` 在异步操作期间循环 SVG 动画，操作成功或失败后均等待下一次 SVG 主动画的完整周期边界再停止。每个动作独立防止重复执行，组件卸载后忽略异步完成通知。

`layout_motion.ts` 对行元素按稳定标识记录位置，在删除、排序和跨命名空间移动后通过 Web Animations 的 transform 插值移动剩余行；支持子树路径重映射和动画中断续接，卸载时取消动画。命名空间开合状态变化时跳过行位移，由 CSS 容器高度过渡带动下方行；ResizeObserver 同步 CSS 布局变化后的行位置，避免后续操作使用过期坐标。减少动态效果偏好下跳过布局移动。
