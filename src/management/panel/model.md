# 工具树管理面板

`management_panel.tsx` 管理草稿、保存、命名空间编辑、内置提示图钉和整理会话草稿入口。`namespace_tree.ts` 处理路径及树变换，`tree_drag.ts` 处理指针拖动，`tree_provider.ts` 投影服务端序列化节点并筛选未挂载工具。样式保存在同目录的 `management_panel.css`。

命名空间树下方显示中英文操作提示，说明展开、编辑、拖动排序、跨命名空间移动及添加工具。

`tools.inspect` 固定映射内置 tools_inspect，启用时始终提示且不可取消固定、改名、拖动或删除，其图钉锁定详细等级 2；tools.profile 子树仅显示 annotation、commands、profiles、load、save、delete、switch、setdefault，均可按 0/1/2 切换提示等级。

普通命令图钉点击按 0（不固定）→ 1（简略）→ 2（详细）→ 0 循环，等级 2 使用黄色实心图钉。固定等级切换时，填充与颜色均渐变过渡。草稿及挂载/移除映射均保留完整等级；命名空间图钉保留布尔开关。树中的固定及关闭图标均为 18px，按钮保持 26px，无边框。

命名空间块统一显示当前层级名称，固定子树 tools.profile 显示 profile，悬停保留完整路径。

namespaceVisible 为随 Profile 保存的命名空间路径 → 固定提示布尔值映射，默认空对象；命令各自保留独立的提示等级。所有模式均不提供 console 命名空间及其命令、查询声明或管理节点；PTC 运行时原生 console 输出对象仍独立可用。

固定命名空间（tools、tools.profile）显示禁用的实心固定图标，提示固定命名空间不可修改；不改变命令各自的提示等级。

顶部工具栏保留“配置文件:” / “Profile:”标签和仅用于设置默认配置的下拉框，隐藏配置管理操作；生成整理提案按钮右对齐。命名空间树标题行右侧的 div 放置独立编辑 Profile 下拉框及刷新、保存、另存为无边框 SVG 图标按钮，不显示 Profile 文本标签。刷新、保存、另存为、下载、上传五个按钮悬停或键盘聚焦时显示功能 Tooltip。树的配置选择不切换默认 Profile，在编辑下拉框底部输入名称并按 Enter 新增本地草稿，点击保存才持久化；默认选择变化时保留编辑草稿。生成整理提案按钮使用原生客户端注入的 organize 能力，以默认模型创建 Intellisense PTC 新对话，预填本地化提示，等待用户手动提交。独立管理页面无原生会话导航能力时禁用该按钮。

管理面板通过同一 profileDraft 投影生成修改判定和保存载荷：映射仅提取当前 Mapping 定义的字段，不透传 enabled 等额外属性；统一补齐可选字段、裁剪挂载路径，并按相同的固定节点和实际路径计算顺序。当前草稿与服务端快照均先规范化，避免仅路径空白或顺序默认值差异导致保存后仍显示已修改。

`error_dialog.tsx` 使用原生模态弹窗展示操作错误及无效编辑反馈，支持确认按钮和 Escape 关闭。保存、另存为和刷新不显示过程状态提示；初次加载及打开整理对话保留过程状态，切换配置不插入过程提示。

首次加载配置时用面板内整块遮罩暂停设置区域交互，加载失败后在遮罩中央显示错误信息，下方显示“重试 / Retry”按钮，不弹出错误对话框；点击重新获取配置，成功后移除遮罩。错误信息保留换行，长内容可滚动查看。

树中 tools.search 默认不固定，图钉支持全部等级，禁用状态随当前 Profile 保存。方法签名从服务端实际工具 schema 的 method 枚举投影。自定义命令及命名空间支持禁用按钮，位置在删除按钮左侧；禁用节点保留可编辑状态并变灰。祖先命名空间禁用时，后代的启用/禁用按钮不可操作，不修改后代自身的禁用配置，也不产生草稿变更；重新启用祖先后恢复后代原有配置。

启用与禁用按钮图标表示当前状态：启用显示圆圈加号，禁用显示圆圈斜线；按钮文字提示仍描述点击后的操作。

拖动到命名空间中心时高亮目标节点；前后插入时，在目标同级节点之间预留空白落位区域，不绘制横线；周围条目使用 transform 平滑让位。命名空间之后的空位位于完整展开子树之后。指针位于空位时保留原插入目标，完成、取消或离开树时释放空位。拖动预览克隆完整块（命名空间包含展开子树）并按抓取位置跟随指针，原位置隐藏块内容且保留占位；完成或取消后恢复。

`tree_nodes/` 按类拆分客户端节点，统一实现 Node 接口和 leaf/tree 类型，详见其 model.md。`tree_node.ts` 只负责组织 NamespaceTree：普通匿名 NamespaceTreeNode 作为根，组合服务器描述的受保护子树和本地草稿映射，路径从 parent 引用派生。父节点 remove 检查子节点 permissions.removable。

服务端 API 的 provided 字段传递完整 SerializedNode 子树及 Permission，包括 removable 和 availableFixLevels；TreeProvider 不导入内置命令表、不按名称分类。ProvidedCommandTreeNode 和 ProvidedNamespaceTreeNode 仅代理这些描述。固定、禁用、删除、拖动和插入均读取权限。固定状态通过通用 namespaceVisible 路径映射保存；协议无 consolePinned/pinField 等特殊字段。受保护命令按钮从左到右为禁用、固定；不可禁用时不渲染禁用按钮，固定等级只有一个选择时锁定。

命名空间与命令节点及其按钮、可编辑文本在聚焦时不显示高亮边框或焦点轮廓；输入框编辑状态、无效命令边框和拖放位置反馈保持各自样式。

树行使用 TooltipProvider 共享浮层，移除名称和注释的原生 title。命名空间展示名称、路径、注释；命令展示名称、灰色命名空间、原始物理名、简化注释、完整文档、全局物理调用次数。原始名可打开工具卡片详情二层 Tooltip。标题后工具 SVG 按钮打开全部工具选择器；未挂载入口保留筛选。

加载快照通过 profileDraft 统一规范化顺序，保留受保护根节点的顺序，避免仅加载配置就显示未保存标记。

每条 Mapping 对应一个挂载路径，同一物理工具可以在树中出现多次。图钉、禁用、简化描述、删除、重命名及拖动均按路径操作，不影响同工具其它挂载路径。选择已挂载工具时新增路径，不移动已有挂载。

另存为右侧依次提供下载、上传 JSON 图标按钮。下载包含当前编辑 Profile 的未保存配置；上传完整校验后替换当前选中 Profile 草稿，名称及默认 Profile 不变，点击保存后持久化。

导入 JSON 仅更新草稿，不替换服务器快照，未保存标记按原快照比较。树、固定节点、未挂载工具、工具 ID 索引及规范化草稿按数据依赖缓存。请求按编辑、全局默认和整理分区标记；Profile 请求使用 inert 暂停相关区域交互，不通过批量 disabled 改变透明度。相同的目录、统计和配置字段保留引用；全局默认更新仅更新默认名称、版本与目录名称，不重建树；切换 Profile 与导入 JSON 保留展开状态，树行按路径复用。

默认 Profile 切换直接使用 POST 响应中的 defaultProfile、revision、profiles 元数据，不额外请求完整工具目录。

默认配置与编辑配置的名称和选项均来自服务端快照；加载完成前选择器为空且禁用，不假定目录中存在名为 Default 的配置。

配置工具栏 SVG 动画由 `animation/action_animation.ts` 跟随实际异步操作：刷新每周期旋转一圈，下载/上传箭头分别向下/向上运动，保存纸张进入档案盒并封口，另存为移动笔；成功或失败后均等到当前完整周期结束。另存为确认名称后、上传选择文件后才开始动画。启用/禁用图标通过 45° 旋转及十字线淡出切换；树展开/收起保留子树至动画完成。删除与拖动排序通过 `animation/layout_motion.ts` 按行位置进行 transform 移动，跨命名空间移动保留来源位置。减少动态效果偏好下缩短开合及操作周期，停用位移。

树详情接收全局 queriesByTool 和 namespaceQueriesByPath；刷新管理快照时同步更新查询次数，命令按物理工具 ID、命名空间按完整路径展示。

Profile 草稿包含可选 brief；未挂载工具按钮右侧提供“编辑配置描述”，应用后标记未保存，保存后持久化。清空描述后省略简介行。默认配置菜单与编辑菜单均显示简介。整理提示要求按界面语言自然生成 Profile 名称与 brief，中文使用通用、基础等名称，命令简略描述继续使用英文。

默认配置文件选择器最小宽度为所在默认配置行的 50%，原生菜单和独立页面选择器共用该宽度约束。

配置描述及命令注释编辑弹窗的底部操作区统一使用 ts-dialog-actions，与另存为等弹窗一致，按钮右对齐。

命名空间块下方的子树容器始终保留，通过 CSS grid 行高及透明度过渡展开和收起，不使用 transform 改变开合位置；下方条目随容器实际高度自然移动。JS 在容器收起过渡结束后清理子树内容，保留容器边界以避免外边距折叠造成间距跳变；开合状态变化不触发行位移动画。

命名空间树下方按当前编辑草稿显示 inspect 不可调用约定警告：inspect 自身或祖先被禁用、或工具未注册，且存在其它启用命令固定等级不是 2 时显示；用户可继续编辑和保存。警告使用黄色边框、半透明黄色背景及一次性缩放淡入动画，减少动态效果偏好下停用动画。修正为等级 2、禁用不满足约定的命令/子树或恢复 inspect 后立即消失，中英文字典提示“固定等级 2，或者禁用”。

首次加载失败的叠层依次显示“刷新”“重置”；重置 POST recover，服务端只丢弃加载失败的数据部分，保留有效配置和统计，成功后重新读取管理状态。

命名空间块仅保留顶部 10px 外边距，子树末项不保留底部外边距，避免动画容器阻止外边距折叠后叠加留白；命名空间与子节点、后续同级条目之间保持 10px 间距。


管理前端优先使用 DSH 样式：NativePanel 注入原生 Button，由 controls/ActionButton 应用于文字操作与弹窗按钮；独立页面使用对应 token 的备用控件。弹窗使用 bg-layer-2、mask、elevation-prominent 与 panel 圆角，输入/菜单/Tooltip 复用主题颜色和字体，键盘焦点使用 DSH focus ring。卡片外框、顶部凸耳及尺寸布局保持不变，仅修改主题样式，保留未挂载工具的错误色及内置卡片的次要文字。无宿主时 light-dark 跟随独立页面 color-scheme。


页面标题右侧的“使用文档”打开 documentation/UsageDialog，按界面语言显示构建时打包的 docs 使用文档及 README 共用的浅色截图。

管理按钮的 Tooltip 解释实际操作效果：默认选择与编辑选择分离，刷新替换未保存草稿、保存不更新已有会话、整理入口仅打开待发送草稿；固定等级提示当前状态及下一次点击效果，锁定的发现工具仅显示锁定说明。禁用说明包含后代影响，移除说明区分挂载与卸载。
