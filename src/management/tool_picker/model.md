# 工具选择器

`tool_picker.tsx` 提供模态工具选择器与 ToolCard，支持名称、路径、描述搜索，以及名称、物理调用次数或全局查询次数升降序排序；排序使用与分组一致的 SVG 图标单选菜单，仅选择默认顺序、名称、调用次数或查询次数，右侧图标按钮统一切换升降序并保留方向；默认顺序时方向按钮禁用。查询次数读取 queriesByTool，未查询工具按 0 排序，次数相同时按名称升序排列。普通卡片点击后将物理工具挂载到目标命名空间；卡片页脚显示全部挂载路径（包含禁用路径）或未挂载状态。未挂载入口默认仅选中未挂载类别，仍可通过筛选菜单切换其它类别。

内置物理命令由服务端 provided 树通过 `providedTools` 投影为 protectedTools，在固定工具类别选中时显示为禁用灰色卡片，不能再次挂载。普通工具不按 tools_ 前缀过滤；PTC 执行入口和原生 exec/run_code 不参与挂载。

`tool_details.tsx` 提供工具卡片和树节点共用的 ToolDetails：头部直接展示原始工具名、来源与完整描述，下方分隔线之后依次为参数、返回类型与调用统计。参数与统计标题在表格外；表格根据内容自适应列宽，参数名称和类型保持单行并按内容占宽，描述列使用剩余宽度并允许换行。

参数类型列保持 object、对象数组和基础类型等简洁标签；完整对象结构、数组、联合、枚举及原始字段注释放在第二层 Tooltip 的代码块中。返回类型不显示根级或字段级描述，使用服务端 outputDeclaration，缺省时由本地 schemaType 转换；二者均直接显示类型表达式，不添加 type 别名或 interface 包装。代码块隐藏宿主标题栏及外框，保留原生 TypeScript 高亮。

ToolStatistics 按物理工具 ID 展示全局累计调用次数，复用于树节点详情；工具选择器底部展示目录中的工具总调用次数。

ToolStatistics 增加全局总查询次数；工具卡片及树命令详情读取 queriesByTool，同一物理工具的别名共享累计值。命名空间复用该表格，仅显示 namespaceQueriesByPath 对应路径的查询次数。

工具选择器按输入 tools、mappings 和 protectedTools 缓存工具 ID 到挂载列表及受保护路径的索引，同时预计算小写搜索文本；输入搜索词和切换排序时复用索引，避免逐工具重复扫描全部映射。


工具选择器使用 DSH 的 bg-layer-2、bg-base、mask、elevation 和圆角 token，弹窗背景不透明；无宿主 token 时通过 light-dark 跟随继承的 color-scheme。独立页面支持系统浅色/深色模式；普通卡片使用可辨识的文字和底色，受保护卡片采用次要文字，避免透明度叠加导致浅色内容难以辨识；保留原有卡片外框、顶部凸耳和尺寸布局，仅适配主题样式。弹窗标题、搜索/排序、滚动卡片区和统计页脚分区显示。

工具卡片详情前增加操作说明：普通工具点击添加到目标分组，内置工具不可重复添加；关闭和排序按钮说明各自作用，排序不改变 Profile 排列。

`tool_filter/` 提供排序方向右侧的 SVG 筛选图标与多选下拉菜单。未挂载、已挂载和内置固定工具为互斥类别，选中类别按并集显示，并与搜索和排序组合；普通入口默认全选，允许全部取消。菜单支持 Tab、空格、方向键、Escape 与外部点击关闭，多选后保持展开。SVG 漏斗在展开或悬停时变形，筛选激活时显示圆点；菜单具有开合动画，并遵循减少动态效果偏好。

工具选择器始终接收前端获取的完整物理工具列表；类别筛选仅在前端执行，后端不按类别细分列表。未挂载数量入口通过 unmountedOnly 初始化多选状态为仅未挂载，不预先裁剪 tools。

排序方向图标由固定路径的箭头和横线组成，通过 transform 过渡实现方向切换动画；减少动态效果偏好下关闭过渡。筛选采用整行按钮作为复选菜单项，文字、勾选图标与空白区域共用同一点击处理，不依赖 label 向 input 转发点击。

工具选择器右上角通过共用 CloseButton 显示 SVG 叉号关闭按钮，保留工具选择器专用的本地化无障碍名称及关闭提示。

工具选择器标题中的目标路径（无路径时显示本地化的“根节点”）采用 13px 常规字重和主题三级文字色，与 18px 的“添加工具”标题区分。

筛选按钮之后依次为分组与视图 SVG 图标按钮，由 `tool_layout/` 共用单选菜单实现，支持键盘导航、Escape、外部点击关闭与开合动画。默认分组为“(无)”，支持按类型（未挂载、已挂载、内置固定工具）或来源组件分组；来源读取 PhysicalTool.source，缺失时归入未知来源。分组保持组内筛选和排序结果，类型按类别顺序、来源按名称排列。默认卡片视图，详细列表显示工具名、来源、描述、挂载路径、调用与查询次数，复用卡片挂载与详情交互。SVG 分组图标在悬停和展开时移动，视图图标随卡片/列表切换形态；减少动态效果偏好下关闭过渡。

弹窗固定占视口宽度的 60%、高度的 80%，最小 900×560px；标题、工具栏和页脚固定，结果区域独立滚动，工具数量及视图切换不改变弹窗尺寸。详细列表首列使用两行：第一行为名称与分号分隔的全部挂载点，第二行为次要浅色描述；其后依次显示来源、调用次数、查询次数。当前宿主 ToolDefinition/get/schemas 不提供来源组件信息，物理目录未获得 source，因此真实宿主目录缺失来源时显示未知来源，不通过名称推断组件；外部明确传入 source 时仍支持分组。

`session_preferences.ts` 使用普通 JS 变量保留当前页面内的视图、分组和类别过滤，关闭并重新打开选择器后恢复，页面重载后重置；首次打开仍按入口初始化类别，后续使用已保留的过滤。搜索、排序和方向仍在每次打开时初始化，偏好不写入 Profile。

详细列表仅工具名文字作为详情 Tooltip 的指针锚点；描述、挂载路径、来源、统计、行空白及行键盘聚焦不触发详情。卡片视图保留整卡悬停和聚焦详情，列表整行仍可点击挂载；Tooltip 沿用共享浮层的延迟关闭与移入交互。

所有工具选择按钮图标均通过 IconProps.valid 控制动画有效性；排序方向显式传 descending，筛选图标显式传 open/active，复选图标显式传 checked。图标组件持有 SVG 和动画样式，外部按钮的 aria/data 属性仅用于按钮语义及布局。
