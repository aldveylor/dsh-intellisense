# 工具选择器

`tool_picker.tsx` 在当前可用物理工具中搜索并选择挂载目标，由父面板提供目标命名空间、可见工具与确认回调。未挂载入口只传入尚未挂载的工具，已挂载工具及失效工具不进入该列表。

卡片底行在绑定路径右侧显示全局 callsByTool 对应的纯数字次数，未调用显示 0。ToolDetails 使用结构化 HTML 构建详情面板布局：顶部突出工具名及可选来源标签，独立描述区域，底部统计栏突出总调用次数；参数及返回值分别使用带标题的表格，列为名称、类型和描述，嵌套字段使用完整路径，数组和组合 schema 保留子项说明；TooltipProvider 共享随鼠标移动的提示组件，支持键盘聚焦。搜索框右侧复用 NativeProfileSelect 只读组件，固定宽度 200px，搜索框占剩余空间；可按默认顺序、名称升降序或调用次数升降序排列，选中后收起，排序不修改 Profile 的命名空间顺序。卡片池底部 footer 左侧显示添加提示及匹配工具数，右侧显示全局 callsByTool 全部明细求和后的所有命令总调用次数，不受搜索、挂载状态或当前卡片列表限制。
