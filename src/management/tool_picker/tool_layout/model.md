# 工具选项菜单

`tool_layout.tsx` 提供排序、分组与视图共用的 SVG 图标单选菜单。父组件持有选择值，菜单管理展开及关闭动画；支持键盘方向键导航、Escape 返回触发按钮、外部指针及焦点关闭。图标形态反映选择状态，悬停和展开提供动画反馈，样式遵循减少动态效果偏好。

菜单遵循图标加文字的纵向布局：触发按钮为 SVG、排序/分组/视图文字及下拉箭头；选项使用对应功能 SVG 图标，当前项通过 aria-checked 驱动整行主题高亮。焦点使用独立轮廓，已选项悬停保留高亮。

排序菜单提供默认顺序、名称、调用次数、查询次数，各项带独立 SVG 图标；触发按钮显示排序 SVG、文字和下拉箭头，并在提示中展示当前选项。排序方向仍由右侧独立按钮切换，默认顺序时方向按钮禁用。

`option_icons.tsx` 将各选项图标拆为独立 React 组件；菜单按选项映射选择组件，不再通过 LayoutOptionIcon 的条件分支拼接 SVG。

`animated_icons.tsx` 提供独立的排序、分组、视图触发图标与下拉箭头组件，通过 open/value 接收动画状态；`animated_icons.css` 管理悬停、展开、选项形态变化及减少动态效果偏好。菜单只选择和使用图标组件，面板样式不再维护这些 SVG 动画。所有图标文件直接位于 tool_layout 目录。
