# Profile picker

`profile_picker.tsx` renders an editor-only configuration selector without the visible Profile label, followed by borderless SVG Add / Refresh / Save / Save as actions. Refresh, Save, and Save as have no hover tooltip or progress message; their accessible names and error reporting are retained. `save_as_dialog.tsx` provides modal name entry for Add and Save as, with input focus, Escape dismissal and Cancel / Confirm actions. Add creates only a local empty draft; Save persists it as a non-default profile. Save as stores a named copy without changing the default profile. Empty or existing names cannot be confirmed.

`ProfileSelect` and `NativeProfileSelect` accept readOnly to suppress creation, renaming and deletion for the default selector, and allowCreate=false to move creation to the external Add button. protectedProfile prevents deleting the last persisted profile even when an unsaved draft is also listed.

`native_profile_select.tsx` implements an independent anchored dropdown styled with host menu theme variables, without the host Menu dependency. `NativeProfileSelect.Item` renders a selection button and a borderless delete button with a 20px icon inside the shared item border; double-clicking the name opens inline renaming (Enter or blur commits, Escape cancels). Selection leaves the dropdown open. The optional bottom input creates an empty profile on Enter; it is hidden in both management toolbar selectors. The panel animates opacity and vertical movement/scale on both opening and closing; closing retains the panel until its own animation ends and blocks pointer interaction. The trigger keeps its chevron aligned to the right and rotates it with a transform transition when expanded. The panel supports arrow navigation, outside dismissal and Escape; composition does not submit names. Persistence remains in the registry and management API.
