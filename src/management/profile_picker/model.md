# Profile picker

`profile_picker.tsx` renders named configuration selection, the draft marker, and adjacent borderless SVG Refresh / Save / Save as actions. The label is localized as “配置文件:” in Chinese and “Profile:” in English; Refresh follows the selector and remains available when the initial view has not loaded. Refresh has no hover tooltip or progress message; its accessible name and error reporting are retained. Save as atomically stores the current draft in a new active profile while preserving the previous saved configuration. Standalone pages retain portable selection and inline management forms.

`native_profile_select.tsx` implements an independent anchored dropdown styled with host menu theme variables, without the host Menu dependency. `NativeProfileSelect.Item` renders a selection button and a borderless delete button with a 20px icon inside the shared item border; double-clicking the name opens inline renaming (Enter or blur commits, Escape cancels). Selection leaves the dropdown open. The bottom input creates an empty profile on Enter. The panel animates opacity and vertical movement/scale on both opening and closing; closing retains the panel until its own animation ends and blocks pointer interaction. The trigger keeps its chevron aligned to the right and rotates it with a transform transition when expanded. The panel supports arrow navigation, outside dismissal and Escape; composition does not submit names. Persistence remains in the registry and management API.
