# 使用方法

在 DSH 中打开 @aldveylor/dsh-intellisense 插件的配置页，即可整理工具和保存配置。页面右上角的“使用文档”可随时打开本文。下方截图使用浅色模式，实际界面跟随 DSH 主题。

## 命名空间：按用途整理工具

命名空间就是工具的分组，可以像文件夹一样嵌套。它让你和 Agent 都能按用途寻找工具。例如，把读写文件的工具放在“文件”组，把搜索工具放在“研究”组；工具较多时，再划分子组。

树中的分组可以展开或收起，工具是分组内的具体操作。名称表示如何找到它，注释说明它的用途。建议使用简短、容易区分的名称，并用一句话写清楚用途；常一起使用的工具放在同一组，避免不必要的层级。

## Profile：保存一整套工具安排

Profile（配置文件）保存工具分组、名称、注释、固定方式和启用状态。你可以分别准备“编程”“研究”等配置，在不同任务中使用。配置描述用来说明整套配置的用途，方便在下拉菜单中选择。

同一个工具可以放进多个配置，也可以在同一配置中放在不同位置。每个位置的名称、注释、固定和禁用状态分别设置；修改或移除其中一处，不影响其它位置，也不会卸载工具。

## Agent 能看到什么

在对话中选择 Intellisense 或 Intellisense PTC 模式后，Agent 会使用该对话选中的工具配置。普通模式仍按 DSH 自身的方式提供工具。Intellisense 适合逐个调用工具；Intellisense PTC 适合把多个工具操作组合完成。两种模式共用你的 Profile。

管理页中的工具目录用于挑选工具，不代表当前 Agent 已经看到所有工具。尚未加入当前配置的普通工具，不会因为出现在管理页就自动提供给该对话；工具还需要在当前对话中可用。

固定等级决定工具在开始时如何提示给 Agent。等级 0（不固定）让 Agent 在需要时查找；等级 1（简略）突出名称和简短用途；等级 2（详细）提供完整调用信息。常用工具可设为详细，偶尔使用的工具可保留按需发现。Intellisense 模式会提供固定工具的调用入口，并在 Agent 查到具体工具后补充其它入口；Intellisense PTC 会按固定等级展示工具提示。

命名空间的图钉用于提示分组的存在，不会把组内所有工具一起设为详细固定。展开或收起分组只是方便你浏览，不改变 Agent 能用哪些工具。禁用工具后，它会保留在配置里，但从发现和执行中移除；禁用整个分组会同时影响它下面的所有工具。

保留内置的工具发现入口，Agent 才能继续查找未详细固定的工具。如果关闭发现入口，页面会在需要时提示你把其它工具全部设为等级 2，或者禁用；你仍然可以继续编辑和保存。

## 页面怎样排布

页面顶部的“默认配置文件”决定新对话默认采用哪套配置，右侧“生成整理提案”用于请 Agent 帮你整理。中间是命名空间树；树标题右侧的配置选择器决定你正在编辑哪套配置，旁边依次是刷新、保存、另存为、下载和上传按钮。把鼠标放在按钮上可查看提示：第一行是动作名称，第二行用浅色文字说明它的作用。

树标题旁的工具图标打开完整工具列表。树下方的“未挂载工具”入口只列出还没有加入当前配置的工具，“编辑配置描述”用于填写配置用途。每一行右侧的图钉、启用/禁用和删除按钮用于调整该行；受保护的内置项目只显示允许的操作。

## 新建、选择与保存配置

在命名空间树旁打开配置菜单，选择要编辑的配置。需要空白配置时，在菜单底部输入名称并按 Enter；需要以当前配置为基础时，点击“另存为”并输入一个新名称。菜单中可以双击已有名称重命名，也可以用删除按钮移除不再需要的配置；最后一套已保存配置不能删除。

编辑后名称旁的星号表示尚未保存。点击“保存”，把当前安排写入这套配置；“另存为”则把当前安排保存为另一套配置。需要修改用途说明时，点击“编辑配置描述”，填写后点击“应用”，再保存配置。

“刷新”重新读取已保存的配置并更新工具列表，会替换当前未保存的编辑。想保留修改时，请先保存或下载。设置顶部的默认配置不会自动切换你正在编辑的配置。

## 添加工具与创建分组

点击“命名空间树”标题旁的工具图标，可把工具加到最外层。想加进某个分组时，展开该分组，点击其中的加号。在弹出的工具列表中，按名称、路径或描述搜索，也可按名称、调用次数或查询次数排序；点击可用的工具卡片完成添加。

工具列表的排序菜单用于选择按名称、调用次数或查询次数排列；旁边的方向按钮切换升序或降序，默认顺序下不可切换。筛选按钮可多选未挂载、已挂载和内置固定工具，筛选和排序都只改变列表显示，不修改配置。

“未挂载工具”入口方便你只查看尚未加入当前配置的工具。卡片下方会显示工具已有的位置；再次添加会新增一个位置。灰色的内置工具卡片不可重复添加。

在树的最外层或分组内，双击“双击创建命名空间”所在的提示文字，输入分组名称，按 Enter 或移开焦点确认，按 Escape 取消。随后用加号添加工具，或把已有工具拖进来。

## 改名、注释与移动

点击分组左侧箭头展开或收起。双击普通分组或工具的名称进行改名，双击注释编辑用途。工具注释编辑框中的“应用”更新当前草稿，“重置”恢复使用原始工具说明，“取消”放弃本次输入；完成后仍需保存配置。

拖动工具或分组可以调整同级顺序，也可以移入其它分组。放到目标分组中间会移入该组；放到条目前后的空位会调整顺序。内置项目的名称和位置受到保护，无法修改的操作会被锁定。

## 固定、禁用与移除

点击普通工具右侧图钉，按“不固定 → 简略 → 详细 → 不固定”循环切换。详细固定使用黄色实心图钉。命名空间图钉只切换是否提示该分组；内置发现工具的固定等级锁定，不能循环切换。

启用状态的按钮显示圆圈加号，点击可禁用；禁用状态显示圆圈斜线，点击可重新启用。禁用行会变灰，配置保留。父分组被禁用时，需要先重新启用父分组，才能调整其下工具的启用状态。

点击删除按钮移除当前工具位置，或删除该分组及其下的内容。禁用适合暂时停用，删除适合清理不再需要的安排。两者都需要保存配置后才能复用。

## 查看工具详情

悬停分组可查看名称、完整位置和说明。悬停工具可查看简化注释、完整说明及统计；再悬停其中的原始工具名，可打开更详细的信息。工具选择器中的卡片也支持悬停查看详情。

详情中可以查看需要填写哪些参数、各参数的类型、工具返回什么以及调用和查询次数。悬停参数类型可进一步查看结构；按住 Ctrl 可固定提示框，再把鼠标移入以滚动查看。次数统计方便你判断哪些工具常用，同一工具不同位置共享工具统计。

## 下载与上传配置

“下载”将当前编辑内容保存为 JSON 文件，包括尚未保存的修改，适合备份或分享。“上传”选择一份配置文件，校验通过后替换当前编辑草稿，保留当前配置名称和默认配置选择；点击“保存”后才会持久保存。文件无效时会提示原因并保留原草稿。

## 在对话中使用配置

整理好后先保存配置，再打开空白对话，选择 Intellisense 或 Intellisense PTC 模式。在对话首页模式旁的配置菜单中选择要使用的 Profile，然后开始对话。若配置按钮置灰，说明当前模式已指定配置，不能在这里切换。

默认配置用于没有指定配置的新对话。已有对话保留自己的工作配置，因此在管理页保存同名配置或更改默认项，不会自动更新已有对话。需要应用已保存的修改时，在对话首页先选择另一套配置，再切回已更新的配置；对话开始后首页菜单会隐藏，可以要求 Agent 切换到指定名称的配置。

## 请 Agent 帮忙整理

点击“生成整理提案”会打开一个预填整理要求的新对话草稿。先查看并按需修改要求，再手动发送。Agent 可据此安排分组、精简注释并保存多套用途不同的配置；完成后回到管理页刷新并检查结果，再选择要使用的默认配置。该按钮在无法打开 DSH 对话的独立管理页面中不可用。
