# 工具管理使用文档

打开插件配置页即可管理可复用的工具 Profile。页面的“使用文档”按钮可在 DSH 内打开本文。截图统一使用浅色模式，界面跟随 DSH 的主题。

## 选择与保存配置

默认配置用于新对话；命名空间树旁的配置选择器用于选择当前编辑目标。“保存”将草稿写入目录，“另存为”创建具名副本，星号表示未保存修改。已有对话保留自己的工作配置，直到为该对话切换配置。

![命名空间树与配置操作](../../assets/zh/namespace_table.png)

## 添加工具

点击“命名空间树”旁的工具图标可添加到根节点，点击命名空间内的工具图标可添加到该节点。“未挂载工具”数量打开筛选后的列表。按名称、路径或描述搜索，选择排序后点击可用卡片完成添加。内置工具卡片不可重复添加。同一物理工具可以拥有多个独立挂载路径。

![浅色模式的添加工具界面](../../assets/zh/tools.png)

## 编辑与发现

展开分组，双击普通节点的名称或描述进行编辑，通过拖动调整结构。固定等级依次为 0（按需发现）、1（简略提示）和 2（完整定义）。禁用保留配置，同时将该节点及后代移出发现与执行。受保护成员的名称、位置和权限由服务端规则约束。

悬停工具可查看参数、返回类型和累计调用次数。按住 Alt 可固定提示框，再悬停参数类型查看结构。树节点详情中的原始命令可展开物理工具详情。

![工具详情](../../assets/zh/tooltip.png)

## 通过工具保存与应用

先读取 `tools.profile.annotation` 中的写入模型。`save` 接收 ProfileWrite：从读取结果中移除 name，并递归移除 permissions，目标名称通过独立参数传入。 匿名根仅接受 type 和 children；固定等级、禁用状态与描述应设置在其成员上。`apply` 接收递归的部分写入树，null 删除可选字段或具名子节点。改名或移动时同时删除旧 children 键并添加新键。

两种操作都只保存目录，保留当前对话草稿。使用 `load(name)` 验证目录中的挂载；`commands.paths` 表示当前对话路径，显式 `switch(name)` 后才更新。不传名称的 apply 从当前对话草稿开始，连续编辑已保存的目录配置时应显式传入名称。

完整 save 默认禁用 tools 命名空间，需显式设置其 disabled 为 false 才启用；apply 省略该字段时保留原状态。允许禁用 inspect，但当它不可用时，其它所有启用命令应固定为等级 2。未满足时返回非阻断警告，不自动修改配置。成功返回 null 或警告，不提供修改摘要；非法或越权写入抛错。
